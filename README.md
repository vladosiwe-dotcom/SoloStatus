# Solo Status System

RPG-мод для **Minecraft 1.21.1 / NeoForge** в духе системы охотника из Solo Leveling. Он даёт игроку уровни, характеристики, классы и специализации, адаптивное пробуждение навыков от боевого опыта, мастерство оружия, качество оружия, Hunter Rank, скрытые достижения и голографическое окно статуса.

> Статус: **исходный код первой версии**. Сборка и запуск в этой среде не проверялись: в облачном окружении закрыт доступ к Maven NeoForge. Проект нужно собрать на своём ПК (инструкция ниже). Ошибки компиляции, если появятся, присылайте логом, они будут исправлены.

## Сборка на ПК

Требования: **JDK 21** (например, [Adoptium Temurin 21](https://adoptium.net/)) и интернет.

```bash
# Windows
gradlew.bat build
# Linux / macOS
./gradlew build
```

Готовый мод появится в `build/libs/solostatus-0.1.0.jar` (около 26 МБ: внутри библиотека распознавания речи Vosk для Windows, Linux и macOS). Его нужно положить в папку `mods` клиента или сервера с **NeoForge 21.1.x** для Minecraft 1.21.1.

Запуск для разработки:

```bash
gradlew.bat runClient    # клиент с модом
gradlew.bat runServer    # выделенный сервер (проверка, что клиентский код не грузится на сервер)
```

Для работы с проектом в IntelliJ IDEA: *File → Open* → папка проекта, дождаться импорта Gradle.

Если не скачивается версия NeoForge или плагина ModDevGradle, поменяйте `neo_version` в `gradle.properties` или версию плагина в `build.gradle` на актуальную 21.1.x / 2.0.x с https://projects.neoforged.net/neoforged/neoforge.

## Как играть

| Действие | Клавиша по умолчанию |
|---|---|
| Окно Системы | **K**, голосом «Система, покажи статус» / «Система, навыки» или той же фразой в чате |
| Следующее окно Системы | **Tab** |
| Голос по клавише (режим ptt) | **B** |
| Осмотреть игрока под прицелом | **I** |
| Активные навыки 1–4 | **Z, X, C, V** |

Все клавиши переназначаются в *Настройки → Управление → Solo Status System*.

1. Нажмите **K**, чтобы пробудить систему и выбрать класс: Воин, Убийца, Маг, Защитник, Лучник или Поддержка. Класс сразу даёт 2 стартовых навыка (активный и пассивный).
2. За каждый уровень (максимум 100) даётся **3 очка характеристик** (СИЛ, ЛОВ, ВОС, ВЫН, ИНТ, УДЧ). Они распределяются вручную на вкладке «Статус».
3. На **5 уровне** открывается выбор одной из двух специализаций класса.
4. Навыки класса покупаются за **очки навыков**. Навыки оружия и скрытые навыки **пробуждаются сами** от реального боя: мастерства, парирований, уклонений, побед над сильными врагами.
5. С **40 уровня** доступно **Испытание смены пути**. Оно открывает высшее умение класса.
6. **Сфера перерождения** (крафт: незерская звезда, аметист, эхо-осколки; иногда падает с боссов) позволяет перераспределить навыки или характеристики.

**Голосовые команды (Vosk, офлайн).** При первом входе в мир нажмите сообщение в чате, чтобы скачать модель (~45 МБ). Это то же самое, что `/systemvoice download`. Распознавание работает только на вашем ПК. Режимы: `/systemvoice always|ptt|off`. Подробности в [docs/INTEGRATIONS.md](docs/INTEGRATIONS.md).

Админ-команды для тестов (уровень прав 2): `/solostatus xp|level|statpoints|skillpoints|mastery|counter|reset|quality ...`
