## Подтверждённые механизмы (стандартный API NeoForge/Minecraft)

- Data attachments, data components, networking payloads, ModConfigSpec, global loot modifiers, ItemAttributeModifierEvent, события урона, блока, смерти и добычи, GUI layers, key mappings.
- **Iron's Spells, атрибуты.** Модификаторы применяются через ванильный реестр атрибутов по id `irons_spellbooks:spell_power`, `max_mana`, `mana_regen`, `cooldown_reduction`, `<школа>_spell_power`. Если атрибут не найден, модификатор просто не ставится.
- **Iron's Spells, школа магии по урону.** Тип урона `irons_spellbooks:<школа>_magic` используется для магического мастерства.
- **Epic Fight, урон.** Атаки Epic Fight проходят через стандартные события урона, поэтому STR, PER, крит, мастерство, качество оружия и пассивки к ним применяются. AGI повышает атрибут скорости атаки, от которого Epic Fight масштабирует скорость анимаций.
- **Legendary Tooltips.** Качество выставляет ванильный компонент `minecraft:rarity`. По нему Legendary Tooltips выбирает рамку по умолчанию, а цвет названия меняется даже без этого мода.

## Iron's Spells — сверено с исходниками

Все имена ниже сверены с исходным кодом Iron's Spells, ветка `1.21` (версия 1.21.1-3.16.3, https://github.com/iron431/irons-spells-n-spellbooks). Интеграция работает через отражение и реестры, поэтому мод собирается и работает без Iron's Spells.

| Что | Имя в Iron's Spells | Что будет, если в другой версии изменится |
|---|---|---|
| Событие применения заклинания | `io.redspace.ironsspellbooks.api.events.SpellOnCastEvent` (наследник `PlayerEvent`): `getEntity()`, `getSchoolType()`, `getSpellLevel()`; школа: `SchoolType.getId()` | в логе будет предупреждение, мастерство магии продолжит расти от урона заклинаниями |
| Атрибуты | `irons_spellbooks:spell_power`, `max_mana`, `mana_regen`, `cooldown_reduction`, `<школа>_spell_power` (fire, ice, lightning, holy, ender, blood, evocation, nature, eldritch) | модификатор не применится, ошибки не будет |
| Типы урона | `irons_spellbooks:<школа>_magic` | мастерство запишется под полным именем типа |

## Epic Fight — реализовано по настоящему API

Интеграция построена по jar `epic-fight-21.17.3.1-mc1.21.1-neoforge.jar`: все классы, методы и поля сверены через `javap`. Вызовы идут через отражение, поэтому мод собирается и работает без Epic Fight.

| Что | API Epic Fight | Поведение |
|---|---|---|
| Анимации навыков | `LivingEntityPatch.playAnimationInClientSide(AssetAccessor, float)`, `Animations.<ИМЯ>` | Анимацию видят сам игрок и все вокруг. Сервер не запускает фазы атаки анимации, поэтому **урон не удваивается**: его считает навык Системы. 21 анимация, все имена проверены. Список в `skill/SkillAnimations.java` |
| Уклонения | `EpicFightEventHooks$Entity.ON_DODGE` (`DodgeEvent`) | засчитываются в счётчик уклонений и открывают окно контратаки |
| Парирование и блок | `EpicFightEventHooks$Entity.TAKE_DAMAGE_INCOME` (`TakeDamageEvent$Income.isParried()`, `getResult() == BLOCKED`) | парирование → «идеальная защита», блок → «блоки». Подписка с приоритетом −100, чтобы прочитать результат после навыка защиты Epic Fight |
| Урон атак | стандартные события урона NeoForge | все бонусы Системы применяются к атакам Epic Fight |

Если какой-то части API нет (другая версия Epic Fight), она отключается с сообщением в логе, а остальное работает.

## Голосовые команды (Vosk) — реализовано

Распознавание речи работает **локально** на ПК игрока через [Vosk](https://alphacephei.com/vosk/) (`com.alphacephei:vosk:0.3.45`, Maven Central). Библиотека встроена в jar мода (Jar-in-Jar) вместе с нативными файлами для Windows x64, Linux x64 и macOS. Звук с микрофона сразу передаётся в Vosk, нигде не сохраняется и никуда не отправляется.

**Первый запуск**
1. Войдите в мир. Если модели нет, в чате появится кликабельное сообщение. Нажмите его и затем Enter, это выполнит `/systemvoice download`.
2. Модель скачается с alphacephei.com (`vosk-model-small-ru-0.22`, ~45 МБ, или английская `vosk-model-small-en-us-0.15`) и распакуется в `config/solostatus/vosk/`. Её можно скачать и распаковать туда же вручную.
3. В углу экрана появится индикатор «● ГОЛОС». Скажите **«Система, покажи статус»**.

**Команды голосом** (русский / английский):
| Фраза | Действие |
|---|---|
| **«Система»** или **«Статус»** (одно слово, сказанное отдельно) | открыть окно; повторно — закрыть |
| «Система, покажи статус», «Система, открой статус», «Покажи статус» | открыть окно статуса |
| «Система, навыки» | открыть окно навыков |
| «Система, закрой», «Закрой статус» | закрыть окно |
| «Система, осмотр» / «Система, оценка» | осмотреть игрока под прицелом |
| «Навык один» … «Навык четыре» | применить навык из слота |
| своя фраза из `chatPhrase` в клиентском конфиге | открыть окно статуса |

**Режимы** (`config/solostatus-client.toml` → `[voice] mode` или команда):
- `/systemvoice always`: постоянно слушать командные фразы (по умолчанию);
- `/systemvoice ptt`: только пока зажата клавиша **B** (переназначается);
- `/systemvoice off`: выключить, микрофон не используется.

Другие команды: `/systemvoice status`, `/systemvoice restart`, `/systemvoice download`. Клавиша **K** работает всегда, независимо от голоса.

**Точность и ложные срабатывания.** Распознаватель получает грамматику, то есть список командных фраз. Поэтому он не расшифровывает обычную речь, а только сопоставляет её с командами. Для одного слова действует дополнительная защита, ведь «система» и «статус» часто звучат в разговоре:
- слово срабатывает, только если сказано **отдельно**: если Vosk услышал вокруг другие слова, это разговор, а не команда («ну система тупит» окно не откроет);
- нужна уверенность распознавания: **≥ 80%** для одного слова, ≥ 60% для фраз;
- после команды есть пауза **1,5 с**, чтобы эхо или повтор не закрыли окно сразу.

Если в голосовом чате всё равно случаются случайные срабатывания, включите режим `ptt`: тогда Система слушает, только пока зажата B.

**Технические решения**
- Функции распознавателя вызываются напрямую через JNA с явной кодировкой UTF-8. Стандартная обёртка `org.vosk.Recognizer` использует системную кодировку, а на русской Windows это cp1251, из-за чего русская грамматика и результаты были бы испорчены.
- Путь к модели передаётся относительно папки игры, только латиницей. Vosk на Windows не открывает пути с кириллицей (например, `C:\Users\Владислав\...`).
- Распознавание идёт в отдельном фоновом потоке, команды выполняются в основном потоке игры.

**Проверено в этой среде:** компиляция голосового модуля с настоящими Vosk 0.3.45 и JNA, загрузка нативной библиотеки Vosk, привязка всех функций распознавателя, корректная ошибка без микрофона, распаковка модели и защита от вредоносного архива, разбор команд.
**Не проверено:** распознавание с реальным микрофоном и моделью (в облачной среде нет микрофона, сайт с моделями заблокирован).

**Совместимость с Simple Voice Chat.** Оба мода могут читать микрофон одновременно: на Windows микрофон работает в общем режиме. На некоторых Linux-системах (ALSA без PulseAudio/PipeWire) микрофон может быть занят, тогда используйте режим `ptt` или `/systemvoice restart`. Брать звук напрямую из API Simple Voice Chat можно отдельным адаптером в будущем.

**Платформы.** В Vosk 0.3.45 нет нативной библиотеки для Windows ARM. На неподдерживаемой системе голос отключится с сообщением в чате, остальной мод продолжит работать.

## Технические риски

1. **Компиляция не проверена в этой среде.** Возможны точечные расхождения сигнатур NeoForge 21.1.x (например, у `LivingShieldBlockEvent`, `CriticalHitEvent`, `MobEffectEvent.Applicable`). Их нужно исправить по логу сборки.
2. Баланс урона рассчитан на ванилу + Epic Fight. С крупными модами на мобов стоит настроить `xpMultiplier` и пороги в конфиге.
3. Модификатор качества `ADD_MULTIPLIED_TOTAL` к атаке складывается с другими модами, которые меняют атаку тем же способом.
