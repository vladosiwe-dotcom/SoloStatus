# Спецификация окна Системы

## Принципы
- **Одно окно — одна задача.** STATUS показывает только характеристики, SKILLS — только навыки, CLASS, MASTERY и ACHIEVEMENTS — отдельные окна. Как в аниме, где окна вызываются по одному.
- **Охотник в центре внимания.** Слева стоит настоящая модель игрока (его скин и броня), справа парит окно. Мир заменяется белым пространством, чтобы ничего не отвлекало.
- **Вложенные окна** (навык, титулы, звуки, подтверждение) открываются поверх основного. Клик мимо или Esc закрывает их. Модальных экранов Minecraft нет, чтобы не разрушать атмосферу.

## Композиция (единицы интерфейса)
| Элемент | Размер / положение |
|---|---|
| Окно | ширина 42% экрана (250–330), высота 80% (214–290), правая половина |
| Переключатель окон | 88×16, слева от окна, шаг 20 |
| Охотник | центр на 27% ширины, ноги на 80% высоты, рост ≈ 64% высоты |
| Табличка заголовка | на верхней кромке окна, по центру, боковые линии по 30 |
| Отступы окна | 14 по горизонтали, первая строка через 18 от верха |

## Шрифты
Exo 2 (OFL) трёх видов: **system** (9.5 — значения и описания), **system_bold** (подписи и названия), **system_title** (15 — цифры уровня, заголовки окон). Кириллица и латиница. Если глифа нет, используется шрифт Minecraft.

## Движение
| Момент | Длительность | Кривая |
|---|---|---|
| Появление белого пространства | 350 мс | ease-out cubic |
| Появление сетки пола | после 35% фона | линейно |
| Появление охотника (подъём на 12) | 450 мс, с задержкой 250 мс | ease-out |

| Проявление строк | 140 мс каждая, шаг 35 мс | линейно |

| Смена окна | повторное раскрытие 220 мс | ease-out cubic |
| Голограмма у другого игрока | раскрытие 260 мс / сворачивание 220 мс | ease-out cubic |

## Звук
Открытие, закрытие, клик, рост характеристики, ошибка и события Системы — каждое со своим звуком (`docs/SOUNDS.md`). В окне STATUS → «Звуки» любой звук можно прослушать.

## Мультиплеер
Игроки рядом видят окно STATUS перед охотником, повёрнутое к смотрящему: имя, уровень, ранг, титул, класс и характеристики. 3D-модели и навыков в нём нет. Скрытый профиль показывает только имя, уровень, ранг, титул и класс.
