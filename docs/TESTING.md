# Чек-лист проверки

## Сборка
- [ ] `gradlew build` без ошибок
- [ ] `gradlew runServer`: сервер стартует, в логе нет `ClassNotFoundException` / `Attempted to load class ... for invalid dist`
- [ ] `gradlew runClient`: клиент стартует, мод виден в списке модов

## Одиночная игра
- [ ] Подсказка «Нажмите K, чтобы пробудиться» вверху экрана
- [ ] K открывает окно с анимацией, повторное K или Esc закрывает
- [ ] Выбор класса через подтверждение; стартовые навыки в слотах Z/X
- [ ] Навык применяется: частицы, звук, перезарядка на панели, расход энергии
- [ ] Победы над мобами дают опыт; уровень повышается с уведомлением и восстановлением здоровья
- [ ] Распределение очков (+ и Shift +5), здоровье и скорость меняются
- [ ] `/solostatus level @s 5`: доступен выбор специализации
- [ ] `/solostatus mastery @s sword 8000`: пробуждается «Крестовый разрез» (событие, частицы, окно)
- [ ] Изучение и улучшение классового навыка за очки; сравнение рангов в панели
- [ ] Дерево: связи, заблокированные узлы, «???» у скрытых
- [ ] Оружие из сундука/крафта получает качество, подсказка показывает редкость и параметры
- [ ] `/solostatus quality 4`: легендарное качество, цвет названия
- [ ] Блок щитом сразу после поднятия засчитывается как идеальная защита
- [ ] Смерть: уровень, навыки, мастерство сохраняются
- [ ] Выход и вход: всё сохраняется
- [ ] Сфера перерождения: окно подтверждения, сфера списывается, очки возвращаются
- [ ] Фраза «Система, покажи статус» в чате открывает окно и не уходит в чат

## Голос (Vosk)
- [ ] При входе в мир без модели появляется кликабельное сообщение; `/systemvoice download` показывает прогресс и устанавливает модель
- [ ] Индикатор «● ГОЛОС» в правом верхнем углу
- [ ] «Система, покажи статус» открывает окно, «Система, закрой» закрывает
- [ ] «Навык один» применяет навык из слота Z
- [ ] `/systemvoice ptt`: распознавание только при зажатой B; `/systemvoice off` выключает микрофон
- [ ] Путь игры с кириллицей (например, `C:\\Users\\Владислав`) не мешает загрузке модели
- [ ] Выделенный сервер стартует без ошибок (голосовой модуль только клиентский)

## Мультиплеер (выделенный сервер, 2 клиента)
- [ ] У каждого игрока свой профиль
- [ ] I на другом игроке: базовая информация; с «Оценкой» расширенная
- [ ] Скрытый профиль показывает только имя, уровень и ранг
- [ ] Поддержка лечит и усиливает союзника
- [ ] Навыки по площади не задевают других игроков

## Совместимость
- [ ] С Epic Fight: бонусы применяются к атакам, скорость анимаций растёт с AGI
- [ ] С Iron's Spells: INT повышает spell_power и max_mana (видно в атрибутах), урон заклинаниями развивает мастерство школы
- [ ] Без обоих модов: мод работает полностью
